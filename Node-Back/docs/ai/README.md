# СТАРТЕР — AI Simplification 6A

Серверная генерация понятных описаний вакансий. Каталог и оригинальное описание продолжают работать без ИИ.

## HTTP API

Все маршруты требуют Bearer JWT.

- POST /api/vacancies/:id/summary — идемпотентно ставит активную версию вакансии в очередь; 202 pending/processing, 200 done, 404 archived/not found, 503 при отсутствии настройки ИИ.
- GET /api/vacancies/:id/summary — читает текущую версию без генерации. Результат \`{status,display,summary,errorCode?}\`, где status = pending/processing/done/failed/unavailable; display = ai/original. При unavailable/failed всегда можно показать оригинальную вакансию.
- Нет конфигурации модели — GET возвращает unavailable. Ни один запрос не блокируется на вызове LLM.

## Запуск

Серверный Node-Back/.env (никогда не размещать в Vite):

    OPENAI_BASE_URL=https://api.openai.com/v1
    OPENAI_API_KEY=...
    OPENAI_MODEL=...

Из каталога Node-Back:

    npm run typecheck
    npm run build
    npm run test:ai
    npm run ai:worker

Отдельный тест MySQL на изолированной базе и активной seed-вакансии:

    AI_TEST_VACANCY_ID=4 npm run test:ai:integration

## Очередь и безопасность

Используется существующая таблица \`vacancy_ai_summaries\` в канонической 17-табличной схеме: уникальный ключ (vacancy_id, provider, model, prompt_version, source_hash).

Worker — отдельный процесс. Запросы берутся короткими транзакциями SELECT ... FOR UPDATE SKIP LOCKED, lease на 90 секунд и случайный токен; сетевой запрос выполняется после COMMIT. Поздние завершения не перезаписывают результат. Максимум три попытки, backoff 10/20 секунд и восстановление устаревших lease.

Результат LLM валидируется Zod, дополнительные числовые утверждения и контакты отклоняются. Сырой ответ модели и ключи не сохраняются/не логируются. Изменение содержимого вакансии автоматически исключает старый кеш. ИИ не гарантирует фактическую достоверность качественных перефразирований — необходимо проверять реальные примеры.

Перед общедоступным запуском добавить rate limiting/квоты на POST и мониторинг расходов на модель. Ключи провайдера, база и LLM в ChatGPT не доступны: проверка сборки и реальный интеграционный прогон должны быть выполнены в целевом окружении.
