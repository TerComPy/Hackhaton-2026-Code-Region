# Стартер — фронтенд

Откройте `index.html` в браузере. Сайт написан на чистых HTML, CSS и JS, сборка не нужна.

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка: главная, подбор профессии, избранное, профиль, карточка вакансии |
| `styles.css` | Дизайн-токены (цвета, отступы, шрифты), светлая и тёмная темы, адаптив |
| `data.js` | Демо-каталог: 14 вакансий из трёх источников («Работа России» / trudvsem.ru, hh.ru, SuperJob), оригинал и пересказ, направления для подбора |
| `scene.js` | 3D: кольцо профессий, сцена «Как это работает», параллакс |
| `app.js` | Каталог, фильтры, избранное, карточка вакансии, подбор, профиль, тема, маршруты |
| `DESIGN.md` | Дизайн-документ: принципы, токены, компоненты, правила 3D |

## 3D

Всё сделано на CSS 3D-трансформациях без WebGL, поэтому текст остаётся чётким.

- **Кольцо профессий** на первом экране. Его можно крутить мышью или пальцем, а клик открывает вакансию. Работает и с клавиатуры: Tab и стрелки.
- **«Как это работает»** привязано к прокрутке. Объявления с трёх площадок склеиваются в одно, карточка переворачивается с текста работодателя на пересказ, и появляется объяснение, почему вакансия подходит.
- **Карточка вакансии** выезжает с поворотом. Переключение «Простыми словами / Как у работодателя» переворачивает описание.

Если в системе включено уменьшение движения, автоматическое вращение и плавные переходы отключаются.

## Что демонстрационное

- Вакансии и компании вымышлены. Кнопка «Открыть на …» ведёт на поиск похожих вакансий на исходной площадке.
- Подбор ищет в рассказе пользователя ключевые слова (`analyze` в `app.js`) и цитирует фразы, на которые опирается. Чтобы подключить языковую модель, нужно заменить эту функцию запросом к серверу, который возвращает ответ того же вида.
- `fetchJobs` в `app.js` имитирует запрос к API агрегатора.
- Регистрация и вход демонстрационные: один локальный профиль на браузер, имя и email лежат в `localStorage`. Пароль проверяется только на длину и не сохраняется. Для настоящих аккаунтов нужен сервер авторизации.
- Избранное, рассказ о себе и тема хранятся в `localStorage`.

Фотографии взяты с Unsplash и загружаются по ссылкам с images.unsplash.com.
Прошлая версия сохранена в папке `_old-version/`.
