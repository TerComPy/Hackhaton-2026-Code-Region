# AppWebView — мобильная обёртка сайта «Стартер»

Отдельное приложение на .NET MAUI, которое открывает **https://starterjob.ru** во встроенном WebView.
Нативный клиент `AppNative/` не затрагивается: это независимый проект.

## Что умеет

- Открывает `starterjob.ru` на весь экран (с учётом системных отступов и клавиатуры).
- Экран загрузки при старте и тонкая полоска прогресса при переходах.
- Экран «Нет интернета / сайт не отвечает» с кнопкой «Повторить»; когда сеть появляется, страница перезагружается сама.
- Кнопка «Назад» на Android переходит назад по истории сайта, а не закрывает приложение.
- Ссылки на внешние сайты (работодатели, «Работа России» и т.д.) открываются в системном браузере, `tel:` и `mailto:` — в соответствующих приложениях.
- Включены JavaScript, localStorage и cookies, поэтому вход в аккаунт сохраняется между запусками.

Список доменов, которые остаются внутри приложения, — в `SiteConfig.cs` (`InternalHosts`).
Если на сайте появится вход через внешний сервис (VK ID, Госуслуги), добавьте его домен туда.

## Запуск

Нужен .NET 11 SDK с workload `maui` (как и для `AppNative`).

```bash
cd AppWebView

# Windows
dotnet build -t:Run -f net11.0-windows10.0.19041.0

# Android (эмулятор или устройство)
dotnet build -t:Run -f net11.0-android
```

Или откройте `AppWebView.slnx` в Visual Studio и выберите платформу.

## Структура

```text
AppWebView/
├── App.xaml(.cs)         # Окно приложения
├── MainPage.xaml(.cs)    # WebView, загрузка, ошибки, «Назад»
├── MauiProgram.cs        # Настройки WebView для Android / Windows
├── SiteConfig.cs         # URL сайта и «свои» домены
├── Platforms/            # Android и Windows
└── Resources/            # Иконка и splash
```
