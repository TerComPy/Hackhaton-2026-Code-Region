# HTTP Foundation — локальная проверка 2026-11-11

Обновление 2026-11-12: прежний 503 устранён на отдельном MySQL 8.4.
Актуальные результаты — [Integration 1.5](../../Node-Back/docs/qa/LOCAL_MYSQL_READINESS.md).

Исходное состояние: HEAD `69e9b1d`, отслеживаемые файлы чистые. Исходники,
тесты и конфигурация frontend сохранены в `.local-backup/frontend-before.tar`
в корне проекта. Существующие неотслеживаемые файлы оставлены на месте.

Vite передаёт `/api` на `http://127.0.0.1:3000`. Для API-режима задайте
`$env:VITE_DATA_MODE='api'` перед `npm run dev` в каталоге Frontend.
По умолчанию сохранён демонстрационный режим. Переключения на mock после
ошибок нет. Каталог, избранное и формы JWT ещё не интегрированы; в API-режиме
демонстрационные записи и пользователь не загружаются в store, форма не
создаёт локального пользователя. Существующая презентационная карусель сохранена.
Диагностический каталог доступен отдельно по `/#/api-preview`.

HTTP-клиент: ошибки ApiError с kind/status/code, таймаут 10 секунд,
AbortSignal и отдельный timeoutMs на запрос, очистка таймеров и слушателей,
204 без чтения JSON, структурированные и не-JSON HTTP-ошибки. Session store
хранит JWT только в памяти; 401 очищает только сессию отклонённого токена.
Нет автоматического повторения запросов или подстановки демонстрационных ответов.

Проверки из Frontend (в среде установлен Chrome):

```powershell
npm run typecheck
npm run build
$env:PLAYWRIGHT_CHANNEL='chrome'
npm run test:smoke -- --workers=2
npm run test:api-mode
npm run test:http
$env:LIVE_API='1'
npm run test:http
```

Typecheck и build успешны. Полный прогон Playwright: 64 passed, 14 skipped
(условия размеров экрана в существующих Perlin-тестах и выключенный live-тест).
Отдельный тест API-режима прошёл: маршруты сохранены, 503 показан пользователю.
Тесты транспорта прошли. Без PLAYWRIGHT_CHANNEL первый запуск не смог запустить
поставляемый Playwright браузер; повтор с Chrome успешен.

Express запущен через `npm run build` и `npm start` в Node-Back, без изменений
его исходников. Реальные запросы напрямую и через Vite proxy:

| URL | HTTP | Тело |
| --- | --- | --- |
| /api/health | 200 | `{"status":"ok"}` |
| /api/ready | 503 | `{"status":"unavailable","database":"error"}` |

Live-тест намеренно завершился ошибкой ожидания 200 на `/api/ready`.
MySQL недоступен для Express; подтвердить успешную готовность нельзя.
Этот endpoint выполняет SELECT 1 и не проверяет миграции/полноту схемы.
Полная приёмка стенда требует доступного MySQL и повторного live-прогона.
