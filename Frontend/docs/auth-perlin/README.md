# Perlin Auth Background

Правая SVG-карта заменена компонентом PerlinOpportunity из подготовленного starter-perlin-vue. Левая форма и размеры карточки сохранены; стили старой карты удалены. Canvas занимает правую панель, надписи находятся поверх него с градиентной подложкой. Панели регулировок нет.

- Canvas 2D: максимум 30 FPS, DPR ограничен 1.5, ResizeObserver, пауза при скрытой вкладке и вне viewport; reduced-motion оставляет статичный фон.
- Сохранены раздвижение точек курсором, волна по клику и всплеск при резком движении.
- При деактивации KeepAlive и перед unmount удаляются обработчики, отключаются observers и отменяется RAF. При возвращении ресурсы создаются один раз.
- Playwright проверяет реальные координаты точек Canvas, частоту отрисовки, обе темы, скрытие вкладки, reduced-motion и очистку ресурсов при переходах.
- 1366×768 и 1280×800: прокрутка по обеим осям 0; переключение входа и регистрации не меняет внешнюю карточку. Ошибок JavaScript нет.
- Typecheck и build успешны.
