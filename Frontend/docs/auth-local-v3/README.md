## Источник переполнения и решение

Старый CSS задавал несколько несовместимых размеров auth-контейнера. Высота от viewport сочеталась с `min-height: min-content`, поэтому intrinsic-высота формы и SVG могла увеличивать grid вопреки заданной высоте. В режиме ошибки форма дополнительно росла. Удаление имени через v-if уменьшало её высоту и заставляло центрированную колонку сдвигаться. Footer уже условно скрывается в App.vue только для гостевой авторизации; этот контракт сохранён.

Теперь у композиции один расчёт: доступная высота `100dvh - header - два внешних отступа`, максимум 800px, минимальная высота 656px по компактной форме. На самом низком обязательном desktop 1366×768 доступно 672px. Правая колонка использует `minmax(0, 1fr)` для SVG; она масштабируется в выделенной области. Ни #app, ни main, ни body не получили overflow:hidden. Ранее существовавший глобальный overflow-x:clip не менялся; новые тесты также сравнивают ширину документа.

Поле имени занимает один обычный слот и в режиме входа: оно невидимо, disabled и inert. Общие поля и CTA остаются на тех же координатах. Высота заголовка, подзаголовка и сообщения ошибки также зарезервирована. Email сохраняется, autocomplete меняется по режиму, пароль можно показать/скрыть. На мобильных высота контейнера естественная; при клавиатуре и ошибках элементы можно прокрутить.

В текущем сообщении нет доступных файлов референсов; композиция сделана по письменному брифу. OAuth и неподключённые ссылки не добавлены.
