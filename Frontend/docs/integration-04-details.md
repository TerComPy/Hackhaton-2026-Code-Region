Integration 04 — Real Vacancy Details

Подключена единая VacancySheet: mock получает прежний Job, API — строковый vacancyId и отдельное состояние useVacancyDetails. Общими остаются dialog, заголовок, факты, анимация, Escape/backdrop и восстановление фокуса. GET начинается при открытии; панель сразу показывает skeleton. Есть error/retry, 404 и предложение войти при 401. Закрытие немедленно отменяет GET/POST; поколение запросов исключает применение устаревших ответов. API-список сохраняет экземпляр панели при сбросе сессии, чтобы сообщение 401 оставалось видимым.

Показаны оригинальные описание, обязанности, требования, навыки, график, опыт, формат, компания, город и зарплата. Отсутствующие разделы скрыты, неизвестные значения подписаны. BIGINT не преобразуются в Number; DECIMAL форматируется как строка, с валютой, периодом и признаком налогов. Переключатель ИИ в API отсутствует, причина объяснена в панели. В mock сохранены переключатель и прежний контент.

Outbound: кнопка резервирует новую вкладку в пользовательском клике, затем POST получает originalUrl. Разрешены только абсолютные HTTP(S) URL. У новой вкладки отсоединён opener. Ошибка закрывает пустую вкладку; если браузер заблокировал вкладку, после успешного POST показывается явная ссылка. При закрытии панели незавершённый переход отменяется. Архивная вакансия доступна для просмотра, кнопка перехода отключена. Переход обозначен как переход, а не отклик.

Фактические HTTP-результаты на MySQL 127.0.0.1:33316 в последнем API-прогоне:

| Запрос | HTTP | Результат |
| --- | --- | --- |
| GET /api/vacancies/4 | 200 | Существующая seed-вакансия, 2 навыка |
| GET /api/vacancies/910000003618884327 | 200 | Активная изолированная MySQL-фикстура; строковый BIGINT, DECIMAL 1234567890.12, навыки |
| GET /api/vacancies/920000000381644259 | 200 | Архивная MySQL-фикстура с отсутствующими значениями |
| GET /api/vacancies/8999999999999999999 | 404 | Отсутствующий ID |
| GET /api/vacancies/:id с недействительным JWT | 401 | Проверены реальный endpoint и сообщение панели |
| POST /api/vacancies/910000003618884327/outbound-click | 200 | Реальный originalUrl и открытие вкладки |
| POST /api/vacancies/920000000381644259/outbound-click | 404 | Переход для архива запрещён сервером |

Контролируемыми сетевыми сценариями дополнительно проверены network error + retry, отмена GET с requestfailed, закрытие во время loading и поздний ответ после открытия другой вакансии; блокировщик popup, javascript: URL и ошибка outbound. Для показа архивного/отсутствующего ID тест подставляет только ответ каталога; запросы соответствующих деталей идут в настоящий API. Тестовые записи создаются отдельно, seed не изменяется; тестовые вакансии, их навыки и клики удаляются в afterAll. Отдельные тестовые аккаунты остаются помеченными TEST FIXTURE.

Проверки: npm run typecheck — успешно; npm run build — успешно; API E2E — 10 passed (21.7 s); полный Playwright с LIVE_API=1 — 106 passed, 68 skipped (1.1 min), без ошибок. Пропуски: 10 API-тестов × 6 mock-проектов = 60 (они проходят отдельно в API-конфигурации); 8 запусков Perlin вне размеров desktop-laptop/desktop-small. Проверены API-панель на 320 и 390 px, opacity:1 и transform:none, фокус после закрытия; mock-тесты панели проверяют кнопки, Escape, backdrop и reduced motion на всех шести размерах.

Backend и механизм авторизации не изменялись. Избранное через MySQL не подключалось. Все изменения локальны; worktree, коммиты, push, PR и merge не выполнялись. Остальные изменения предыдущих этапов сохранены.
