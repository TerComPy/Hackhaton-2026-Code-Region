# Соглашение об именовании

Рекомендую использовать эти префиксы перед изменением в репозитории.
Например:
```fix: sql injection fiexed```

### Основные префиксы коммитов:

Префикс	Назначение	Пример
feat:	Новая функциональность	feat: add user registration
fix:	Исправление ошибки	fix: resolve login failure
docs:	Изменение документации	docs: update README
style:	Форматирование, без изменения логики	style: format API routes
refactor:	Переработка кода без изменения поведения	refactor: simplify auth service
perf:	Оптимизация производительности	perf: optimize vacancy queries
test:	Добавление или исправление тестов	test: add auth integration tests
build:	Сборка и зависимости	build: upgrade express
ci:	CI/CD и автоматизация	ci: add Jenkins pipeline
chore:	Техническое обслуживание проекта	chore: update gitignore
revert:	Откат предыдущего коммита	revert: remove experimental API
